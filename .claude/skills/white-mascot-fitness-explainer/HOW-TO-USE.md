# วิธีใช้สกิล white-mascot-fitness-explainer (คลิปฟิตเนสสายความรู้ หุ่นขาวตาดำ)

สกิลนี้ทำคลิปแนวนอน 16:9 อธิบายความรู้ฟิตเนส/สุขภาพ จากไฟล์เสียงพากย์ ตัวละครหลักเป็นหุ่นกล้ามสีขาว ตาดำวงรี 2 ข้าง ไม่มีปาก
ยืนบนพื้นสีน้ำเงินอมเขียว หรือในฉากการ์ตูนที่แยกเลเยอร์ (ฉากหลัง 1 ชั้น ตัวละคร/พร็อพอีกชั้น) ทำให้ซูมแล้วมีมิติ และตัวละครสไลด์เข้าฉากได้

## ติดตั้ง (ทำครั้งเดียว)
แตกไฟล์สกิล เปิดแอป Claude ไปที่แท็บ Code เลือกโฟลเดอร์สกิลนี้เป็นโปรเจกต์ แล้วพิมพ์ "ติดตั้งสกิล"
(สกิลจะเช็กเองว่าเครื่องมีอะไรแล้ว ขาดอะไรติดตั้งให้อัตโนมัติ)
ใช้บนมือถือ/iPad ได้ทุกขั้นตอน ภาพสร้างใน Google Flow แล้วส่ง zip มาในแชต

## สั่ง Claude ยังไง
1. "คิดบท 90 วิ เรื่อง ..." → ได้ script.txt (มีแท็ก [ผู้เล่า: ...] บรรทัดแรก)
2. "ทำพรอมต์ภาพ" → ได้ agent-prompt.md + รูปใน style-ref/ ทุกรูป (แนบมาในแชตด้วย) เอาไปวางในเอเจนต์ Flow พร้อมแนบรูปทั้งหมด
   - รูปอ้างอิงเป็นภาพที่เราสร้างเองเท่านั้น (EYE-REF.png = หน้าตาตาที่ต้องเป็นแบบนี้ทุกภาพ)
   - พรอมต์บังคับ: ตาดำวงรี 2 ข้างเหมือนกัน มองทางเดียวกัน ห้ามเปลี่ยนรูปตาตามอารมณ์ / ฉากต้องเป็นการ์ตูนเส้นหมึกแบบ B01 B02 B06 B08
3. ส่ง zip ภาพ + ไฟล์เสียง ElevenLabs → Claude ตัดคำเกินช่วงต้น ถอดจังหวะ วางช็อต เรนเดอร์ แล้วส่ง 3 ไฟล์ (มีเพลง / ไม่มีเพลง / ปก)

## ในโฟลเดอร์มีอะไร
- engine/ : render.py (เอนจินเลเยอร์ ซูม/สไลด์ลื่นระดับซับพิกเซล), audio.py (สวูช + pop), cover.py, ฟอนต์ Kanit, เสียงสวูช sw1/sw2
- tools/ : music_synth.py (เพลงสังเคราะห์ที่ทำเอง ใส่เพลงไม่ติดลิขสิทธิ์ของคุณเองแทนได้), new_project.sh, key.py (ไดคัทพื้นเขียว + เปลี่ยนชื่อไฟล์ + บอกว่าขาดภาพไหน), prep_vo.py (ตัดต้นเสียง + ถอดเสียง), stills.sh, render_all.sh, finish.sh
- templates/agent-prompt.md : พรอมต์ภาพ 50 ภาพ (ตัวละคร 23 ท่า + พร็อพ + ฉาก) แก้เฉพาะพร็อพ/ฉากตามเรื่อง
- style-ref/ : EYE-REF.png + ตัวอย่างตัวละคร/ฉาก/พร็อพจากคลิปแรก
- example/sleep-muscle/ : คลิป "นอนน้อยกล้ามไม่ขึ้น" ครบ (ภาพ 50 ภาพ, เสียง, episode.py) เรนเดอร์ซ้ำได้เหมือนเดิมทุกพิกเซล

## รันเองบนเครื่อง (ถ้าต้องการ)
```
bash tools/new_project.sh projects/เรื่องใหม่
python3 tools/key.py projects/เรื่องใหม่ ~/Downloads/zip1 ~/Downloads/zip2
python3 tools/prep_vo.py projects/เรื่องใหม่ vo.mp3 --trim 0.85
# แก้ projects/เรื่องใหม่/episode.py (ดูตัวอย่าง)
bash tools/stills.sh projects/เรื่องใหม่ 2 10 30
bash tools/render_all.sh projects/เรื่องใหม่ 4
bash tools/finish.sh projects/เรื่องใหม่ "ชื่อคลิป"
```
ติดตั้งเองทีละขั้น: ดู `SETUP.md`
